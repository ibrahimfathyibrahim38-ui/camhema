========================================================
        Hema Cam - تعليمات التشغيل على الـ PC والـ Termux
========================================================

--------------------------------------------------------
 1) على الكمبيوتر (Windows)
--------------------------------------------------------

الطريقة الأسهل (ملف جاهز دبل كليك):
  1- افتح مجلد الأداة.
  2- دبل كليك على الملف:  HemaCam-Start.bat
  3- أول مرة هيقوم بتركيب كل حاجة لوحده (WSL + tools) وبعدين
     هيشغّل الأداة مباشرة. بعد أول مرة هيشغّلها على طول.

لو الملف قالك إن WSL مش موجود:
  - افتح "Windows PowerShell" كـ Administrator
  - اكتب:  wsl --install -d Ubuntu
  - سجّل خروج من الويندوز ورجّع (Restart) وبعدين اعمل دبل كليك
    على HemaCam-Start.bat تاني.

الطريقة اليدوية (لو حابب تفهم الخطوات):
  1- ثبّت WSL:  wsl --install -d Ubuntu   (وإعادة تشغيل)
  2- افتح Terminal واكتب:
        wsl
  3- داخل لينكس ثبّت المتطلبات:
        sudo apt update && sudo apt install -y php-cli curl wget unzip git procps
  4- انتقل لمجلد الأداة (ملفوك على C: بتتحول لـ /mnt/c/...):
        cd "/mnt/c/Users/Hema/Desktop/New folder (15)/CamHema/CamHema"
        sed -i 's/\r$//' hema.sh
        bash hema.sh

ملاحظات للـ PC:
  - الويندوز لازم يفضل شغال عليه السيرفر أثناء الاختبار.
  - أي جدار نارية (Firewall) هيسألك — اسمح للـ PHP / WSL.

--------------------------------------------------------
 2) على الهاتف (Termux)
--------------------------------------------------------

  1- ثبّت Termux من F-Droid (مش من Google Play):
        https://f-droid.org/packages/com.termux/
     (لو جوجل بلاي، نسخة قديمة ومش بتدعم كل الحاجات)

  2- افتح Termux ونفّذ بالترتيب:
        termux-setup-storage
        pkg update -y && pkg upgrade -y
        pkg install -y git php curl wget unzip

  3- انقل الملفات من الكمبيوتر للموبايل:
     - حط مجلد الأداة (اللي فيه hema.sh) في ذاكرة الموبايل
       (مثلاً /sdcard/HemaCam) سواء بالكابل أو جوجل درايف.
     - بعدين داخل Termux:
        cp -r /sdcard/HemaCam ~/HemaCam
        cd ~/HemaCam

     (أو لو عايز نسخة من الريبو الأصلي من غير تعديلاتك:
        git clone https://github.com/daxxtropezz/CamHacker
        cd CamHacker )

  4- لو الملفات اتنقلت من ويندوز، صلّح نهايات الأسطر:
        sed -i 's/\r$//' hema.sh

  5- شغّل الأداة:
        bash hema.sh

  6- أول تشغيل هيطلب منك:
     - اختيار القالب (Template)
     - اختيار التونيلر (Tunneler): cloudflared أو loclx
     - لو اخترت loclx هيدخل Authtoken من: https://localxpose.io
     - هيحمّل cloudflared/loclx تلقائياً أول مرة.

ملاحظات للـ Termux:
  - لازم إنترنت شغال (لتحميل التونيلر و إنشاء اللينك).
  - التليفون يفضل شغال والسيرفر مفتوح طول ما انت بتختبر.
  - لو طلب صلاحية التخزين: termux-setup-storage وعمل Restart
    للتطبيق (لمسة على الشاشة) قبل إعادة المحاولة.

--------------------------------------------------------
 3) بعد ما اللينك يشتغل (على الاتنين)
--------------------------------------------------------
  - الأداة هتعرض لينك (cloudflared) + لينك مختصر + متخفي (masked).
  - اللي يفتح اللينك ويسمح للكاميرا، صورته هتتحفظ في:
    - PC:     مجلد Pictures (أو المجلد اللي اختارته)
    - Termux: /sdcard/Pictures
    - اسم الملف بيبدأ بـ HemaCam-
